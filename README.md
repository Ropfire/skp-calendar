# 📅 Автоматическая синхронизация расписания СКП в Google и Samsung Календарь

Автоматический генератор подписки на расписание Сибирского колледжа предпринимательства (СКП) для Google Календаря, Samsung Календаря, Apple Календаря и Outlook.

Расписание обновляется **автоматически в облаке 24/7** через GitHub Actions без необходимости держать компьютер включенным.

---

## ✨ Формат событий в календаре

События оформлены в точности так, как удобно студенту:

* **Заголовок:**
  ```text
  Философия (Л)[15]
  Коваленко Т.Д
  ```
  *(Название предмета, формат `(Л)` / `(П)`, номер кабинета `[15]` и преподаватель)*
* **Место:** `Аудитория 15`
* **Напоминание:** уведомление за 15 минут до начала пары
* **Описание:** номер пары, время (например `10:15–11:45`), группа, преподаватель, формат (очно/дистанционно)

## 🚀 Как запустить автообновление через GitHub (1 раз настроить и забыть)

### Шаг 1. Загрузите код в свой GitHub репозиторий
1. Создайте новый репозиторий на [GitHub](https://github.com/new) (например `skp-calendar`).
2. В папке с проектом выполните:
   ```bash
   git add .
   git commit -m "Initial commit"
   git branch -M master
   git remote add origin https://github.com/<ВАШ_НИК>/<ИМЯ_РЕПОЗИТОРИЯ>.git
   git push -u origin master
   ```

### Шаг 2. Включите GitHub Pages
1. Откройте ваш репозиторий на GitHub → вкладка **Settings** (Настройки).
2. Слева выберите **Pages**.
3. В разделе **Build and deployment**:
   * **Source**: `Deploy from a branch`
   * **Branch**: `master` (или `main`), папка `/docs`
4. Нажмите **Save**. Через 1–2 минуты GitHub Pages опубликует ваш сайт по адресу:
   ```text
   https://<ВАШ_НИК>.github.io/<ИМЯ_РЕПОЗИТОРИЯ>/
   ```

### Шаг 3. Включите права для GitHub Actions
1. В настройках репозитория **Settings** → **Actions** → **General**.
2. Внизу в блоке **Workflow permissions** выберите **Read and write permissions**.
3. Нажмите **Save**.
*(Это нужно, чтобы автобот мог раз в 2 часа обновлять расписание в репозитории).*

## 📲 Как подключить расписание в календари

Ваша ссылка на календарь для группы **ИСиП-23/1**:
```text
https://<ВАШ_НИК>.github.io/<ИМЯ_РЕПОЗИТОРИЯ>/calendars/ИСиП-23_1.ics
```

### 1. Подключение в Google Календарь (Компьютер / Браузер)
1. Перейдите в [Google Календарь](https://calendar.google.com).
2. В левой колонке найдите раздел **«Другие календари»** и нажмите **«+»** → **«Добавить по URL»**.
3. Вставьте ссылку на ваш календарь и нажмите **«Добавить календарь»**.
4. Календарь появится в списке, а события автоматически расставятся по дням недели!

---

### 2. Подключение в Samsung Календарь на телефоне

Есть два простых способа:

#### Способ А (Через Google Аккаунт — Самый удобный)
Если вы добавили календарь в Google Календарь по инструкции выше:
1. На телефоне Samsung откройте приложение **Календарь**.
2. Откройте боковое меню (три полоски слева вверху) → значок **Шестерёнка** (Настройки) → **Синхронизировать**.
3. В списке ваших календарей Google появится календарь **«Расписание ИСиП-23/1»**.
4. Включите галочку напротив него — расписание сразу отобразится на телефоне и будет автоматически обновляться вместе с Google-аккаунтом!

#### Способ Б (Напрямую в Samsung Календарь)
1. Скопируйте ссылку на `.ics` файл.
2. В приложении **Samsung Календарь** откройте боковое меню → **Управление календарями** → **Добавить подписку на календарь** (или Подписка по URL).
3. Вставьте ссылку и сохраните.

## 💻 Локальный запуск (тестирование на компьютере)

Если вы хотите запустить генерацию прямо сейчас на своём ПК:

* **Сгенерировать файл для своей группы:**
  ```bash
  python generator.py --group "ИСиП-23/1"
  ```
  Файл сохранится в папку `calendars/`.

* **Запустить локальный веб-сервер с интерфейсом:**
  ```bash
  python server.py
  ```
  Откройте в браузере: [http://localhost:8000](http://localhost:8000). Там можно в один клик скопировать ссылки или добавить календарь в Google.

## ⏰ Как часто обновляется расписание?
Workflow в `.github/workflows/sync.yml` настроен на запуск **каждые 2 часа** с понедельника по субботу в учебное время. Если администрация колледжа внесет изменения в Excel-файл на сервере, GitHub автоматически скачает изменения и обновит `.ics` файл.
